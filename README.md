# ForMyBot — funding-бот с веб-калькулятором и алертами

Стратегия: заработок на funding с шорта на фьючерсах, хедж — лонг той же
монеты на споте. Бот собирает funding fee с Aster / Bybit / Lighter / MEXC /
Gate, шлёт ежедневный отчёт и отвечает на команды в Telegram, считает
чистую доходность сделок через веб-калькулятор и алертит, когда прогнозный
funding по открытой позиции уходит в минус.

## Компоненты

- `funding_report.py` — вся логика работы с API бирж (история funding,
  список открытых позиций) + сборка текстовых отчётов. Используется всеми
  остальными файлами.
- `bot_poll.py` — обработчик команд `/report`, `/calendar`, `/positions`.
- `bot_worker.py` — постоянный Telegram-бот (long polling).
- `funding_alerts.py` — почасовая проверка прогнозного funding по открытым
  позициям, алерт в Telegram при уходе ставки в минус.
- `calculator.py` — расчёт чистой доходности сделки (funding − комиссии
  открытия + спред спот/фьючерс на входе) за период/биржу/монету.
- `entry_price.py` — авто-подбор цен открытия для калькулятора: цена шорта
  берётся из данных открытой позиции на фьючерсной бирже, цена споta — из
  истории сделок на подключённых спот-биржах (Bybit/MEXC/Gate) вокруг
  момента открытия. Если не нашлось — поле остаётся пустым для ручного
  ввода.
- `app.py` — **точка входа для деплоя**: веб-страница калькулятора (Flask,
  под Basic Auth) + фоново bot_worker + фоново funding_alerts, всё в одном
  процессе/сервисе.
- `.github/workflows/` — альтернативный запуск через GitHub Actions по
  расписанию (не использует app.py/веб-часть).

## Деплой на Railway

`Procfile` содержит `web: python app.py` — Railway поднимет один сервис,
который одновременно: слушает HTTP на `$PORT` (калькулятор) и в фоне гоняет
Telegram-бота и алерты.

### Переменные окружения

Обязательные (как и раньше):

- `ASTER_USER_ADDRESS`, `ASTER_SIGNER_ADDRESS`, `ASTER_SIGNER_PRIVATE_KEY`
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`

Опциональные (биржа участвует в отчётах/калькуляторе/алертах, только если
её пара задана):

- `BYBIT_API_KEY` / `BYBIT_API_SECRET` (+ опционально `BYBIT_PROXY`)
- `LIGHTER_ACCOUNT_INDEX` / `LIGHTER_AUTH_TOKEN`
- `MEXC_API_KEY` / `MEXC_API_SECRET` (+ опционально `MEXC_PROXY`)
- `GATE_API_KEY` / `GATE_API_SECRET` (+ опционально `GATE_PROXY`)

Новые, для веб-калькулятора и алертов:

- `WEB_APP_USERNAME` — логин для входа на страницу калькулятора (по
  умолчанию `admin`).
- `WEB_APP_PASSWORD` — **обязательно задать**. Без него страница
  калькулятора отдаёт 500 и не показывается вообще — это осознанная защита
  от случайной публикации финансовых данных без пароля на публичном
  Railway-домене.
- `ALERT_CHECK_INTERVAL_MINUTES` — как часто проверять прогнозный funding
  по открытым позициям, по умолчанию `60`.
- `FUNDING_ALERT_THRESHOLD` — порог в долях (не в процентах), по умолчанию
  `0.0` (алерт при любой отрицательной прогнозной ставке).

### Локальный запуск для проверки

```bash
pip install -r requirements.txt
export ASTER_USER_ADDRESS=... ASTER_SIGNER_ADDRESS=... ASTER_SIGNER_PRIVATE_KEY=...
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...
export WEB_APP_PASSWORD=changeme
PORT=8080 python app.py
```

Калькулятор — на `http://localhost:8080/` (логин `admin` / `changeme`).

## Калькулятор — как считает

Для выбранной биржи/монеты/периода:

```
net = funding_income − opening_fees + spread_effect
```

- `funding_income` — сумма фактических выплат funding по фьючерсной позиции
  за период (из истории биржи).
- `opening_fees` — komиссии открытия обеих ног: `qty × цена_спота ×
  spot_fee_pct + qty × цена_фьючерса × futures_fee_pct`. Ставки — taker,
  дефолты без VIP-скидок, **переопределяются вручную** в UI под свой
  аккаунт.
- `spread_effect` — `(цена_фьючерса − цена_спота) × qty`, ценовой спред
  между ценой исполнения фьючерсного шорта и спотовой покупки в момент
  открытия.

  Обе цены калькулятор пытается подобрать САМ при выборе конкретной монеты
  (не «все открытые позиции»): цена фьючерса — из данных текущей открытой
  позиции на бирже; цена споta — из истории сделок на всех подключённых
  спот-биржах (Bybit/MEXC/Gate — у Aster/Lighter споta нет вовсе) в окне
  времени вокруг момента открытия шорта (±20 мин, если биржа отдаёт точное
  время открытия — Bybit/MEXC; ±6 часов, если время оценено приблизительно
  по непрерывности funding — Aster/Gate/Lighter). Если подходящая
  спот-сделка не нашлась ни на одной бирже — поле остаётся пустым, и его
  нужно заполнить вручную. Оба поля в любом случае остаются редактируемыми
  перед расчётом.

## Алерты по открытым позициям

Раз в `ALERT_CHECK_INTERVAL_MINUTES` минут для каждой открытой сейчас
позиции запрашивается прогнозная (не историческая) ставка на СЛЕДУЮЩУЮ
выплату funding через публичные эндпоинты бирж. Алерт в Telegram уходит
один раз при переходе ставки из неотрицательной в отрицательную по паре
(биржа, символ) — не при каждой проверке, чтобы не спамить.
