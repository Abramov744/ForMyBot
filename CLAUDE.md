# ForMyBot — заметки для Claude

Личный funding-бот (не общий проект, единственный пользователь — владелец
репозитория). Стратегия: шорт на фьючерсах + лонг той же монеты на споте,
доход только с фьючерсной ноги. Подробное описание архитектуры и формул —
в `README.md`, прочитай его первым.

## Стиль кода

- Код и все комментарии — на русском. Комментарии объясняют "почему", а не
  "что" (особенно вокруг особенностей конкретных бирж — там обычно есть
  причина, почему сделано именно так, не переписывай не разобравшись).
- Каждая биржа (Aster/Bybit/Lighter/MEXC/Gate) — набор `fetch_*` функций в
  `funding_report.py`, у каждой своя схема подписи запросов и свой формат
  символов (см. комментарии над каждым блоком). Новый функционал по биржам
  переиспользует эти функции и приватные хелперы (`_get_proxies` и т.п.)
  через импорт, а не копирует логику заново.
- Секреты — только через переменные окружения (`load_secrets()` в
  `funding_report.py`), никогда не хардкодить и не логировать значения
  ключей/токенов.

## Прежде чем менять

- Это финансовый инструмент, работающий с реальными деньгами и реальными
  API-ключами биржи — если не уверен в точном поведении API (формат поля,
  единицы времени мс/с, знак числа), лучше явно спросить в комментарии/PR,
  чем предполагать.
- `app.py` — единая точка входа для деплоя на Railway (веб-калькулятор +
  фоновый Telegram-бот + фоновые алерты, всё в одном процессе). Если меняешь
  что-то в `bot_worker.py`/`funding_alerts.py`, проверь, что `app.py`
  по-прежнему их корректно импортирует и запускает как фоновые потоки.
- Перед коммитом: `python3 -m py_compile` на изменённые файлы как минимум;
  для logic-heavy изменений (расчёты, парсинг ответов бирж) — короткий
  smoke-тест с подменными (не реальными) данными, как уже сделано для
  `calculator.py`/`entry_price.py`/`funding_alerts.py` в истории коммитов.
